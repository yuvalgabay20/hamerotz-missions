# Scaffold UI foundation

This directory is the unmodified shadcn foundation generated by the approved
Sites scaffold. It remains available for future use, but none of its generic
components are part of the current mission-site application surface.

`oxlint` excludes this directory and the paired generated `hooks/` directory.
The lint gate continues to cover all authored application code, tests, and
configuration; any mission-specific component must be added outside this
generated foundation and is linted normally.
